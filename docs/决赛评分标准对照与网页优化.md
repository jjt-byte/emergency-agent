# 芯智涌现 2026 决赛评分对照与网页演示手册

## 五分钟 Demo

首页不再放逐步演示说明。按 [5分钟 Demo 演讲稿](5分钟Demo演讲稿.md) 排练：连续巡查、复合问题与 Agent 的真实工具决策、结果和证据、局限与下一步。先说明演示素材与 CPU 后端，再讲能力；不要把静态照片拼接素材描述成摄像头实况。

不要把结构化动作或规则校验包装成语言模型隐藏思维链；可审计的决策和执行记录足以说明谁选择了什么工具。不要把检测置信度说成火灾概率，不要把照片序列称为真实连续视频，不要把无检出说成安全。

## 页面数字来自哪里

服务端 /api/evaluation 从本机验证文件即时汇总快照。该评测快照不放在主界面；设备状态条由 /api/status 提供当前配置与就绪状态。主要来源为：

- data/person_detection_validation.json：6 张人员推理记录（其中包括空白负样例），耗时包括文件中记录的单图推理时间；count 是已有记录字段，不是独立人工标注真值。
- data/fire_smoke_validation.json：3 张人工标注正样例和 1 张负样例。按正样例中是否检出任一 fire/smoke 计算演示计数；现有结果是 3 张正例仅 1 张有检出，确实存在漏检。
- /home/orangepi/models/qwen2.5-3b/benchmark.json：CPU 基准，提示处理和生成阶段各 2 次；本地 Agent 整轮还会包含提示词处理、模型多轮规划、工具执行和最终回答，故不能直接用 tokens/s 推算总响应时间。
- data/reports/20261123-221124-5985a2.json：一次在本板运行的真实端到端 Agent 样例，烟火检测后调用两次本地知识检索，第三轮结束并通过回答校验；耗时 50.153 秒。它是一次观察，不能当作平均延迟或稳定性统计。
- data/monitor/photo-suite-smoke-test.json：静态照片序列流程测试，36 帧和 6 条按类别合并的事件记录，不是实景视频测试。
- data/monitor/sessions/dd8bcc2d6c234a9096084f4032a28178/test-summary.json：10.967 秒游客实拍片段，间隔 2 秒抽样，共 6 帧；作为人员和烟火负例，没有人数真值。
- `/api/evaluation` 的历史评测快照另含逻辑核数、系统可用内存和 1 分钟负载；这些值不显示在首页，也不是模型峰值资源、CPU 利用率或功耗测量。

## 仍值得优先补齐

1. **真实视频与摄像头接入：** 当前持续监测可以处理本地视频，照片拼接素材只验证抽帧、检测和事件记录流程。要展示持续巡查的实际价值，还需接入摄像头或 RTSP，并用带逐帧真值的现场视频测试。
2. **报警链路：** 当前页面能记录事件，也可在浏览器启用提示音；没有板载蜂鸣器或远程通知。接入硬件或通知服务后，再验证触发延迟、断网恢复和误报警处置。
3. **模型与性能验收：** 烟火验证样本目前存在正例漏检；人员 NPU 候选尚未通过验收，当前网页使用 CPU 模型。补充独立标注测试后，再决定是否切换 NPU，并测端到端延迟和长时间运行稳定性。

这些属于演示所依赖的真实场景、报警和模型验证工作。现有首页已经以持续监测为主线，剩余改动优先用于补齐上述可验证能力，而不是继续增加介绍性区块。

旧日期的 JSON 是历史基准，不会因为页面刷新就自动重新跑检测。修改模型、阈值、配置或硬件后，要重新测量并更新对应原始验证记录；否则应继续按历史快照标注。

## 复现与材料

从项目目录运行网页：

    cd /home/orangepi/emergency-agent
    ./start-web.sh --host 0.0.0.0 --port 8080

在本机浏览器访问 http://127.0.0.1:8080；局域网演示时，在板卡终端执行 hostname -I，从同一网络访问板卡地址。启动后刷新页面以读取最新服务端代码。桌面应用安装见[桌面版使用说明](桌面版使用说明.md)，已有技术参数与 PPT 整理见[技术白皮书与 PPT 素材](技术白皮书与PPT素材.md)。

相关检查可在项目目录执行：

    python3 -m unittest discover -s tests -p 'test_webapp.py'
    python3 -m unittest discover -s tests -p 'test_agent_loop.py'
    node tests/test_ui.js
    node tests/test_ui_competition.js
