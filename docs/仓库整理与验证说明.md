## 本机验证

执行环境为 Windows、Python 3.12.14 和 Git 自带 Bash。运行测试前生成了临时本机配置，成品由已审查的 Git 文件清单导出。

| 检查项 | 结果 |
|---|---|
| Python 源文件语法解析 | 47 个文件通过 |
| Shell 语法检查 | 10 个脚本通过 |
| 前端 Node.js 测试 | 6 组通过 |
| 可移植 Python 单元测试 | 100 项通过，含 8 项启动回归 |
| Windows 全量收集尝试 | 收集 109 项，报告 1 个失败、10 个错误 |
| Git 文件与大小检查 | 125 个文件，最大文件为约 1.21 MB 的白皮书 PDF |
| Markdown 相对链接检查 | 文档链接可解析，本地生成资源以路径说明 |
| 常见凭据模式扫描 | 未发现匹配项 |

Windows 全量尝试中的错误涉及 `fcntl`、`os.killpg`、`os.getpgid`、`os.getloadavg` 与失败后的进程、文件清理。`test_monitor.py` 因缺少 `fcntl` 导入失败，因此全量收集数也受平台影响。

可移植测试运行时排除了 `test_monitor.py`，以及以下依赖 Linux 接口的 8 项测试。源码中的完整测试保留供 Linux 和 CI 执行。

```text
test_desktop.DesktopBackendTests.test_early_exit_is_reported_and_resources_are_closed
test_desktop.DesktopBackendTests.test_owned_service_reads_actual_port_and_stops_its_private_group
test_desktop.DesktopBackendTests.test_recognized_external_service_is_reused_and_never_stopped
test_desktop.DesktopBackendTests.test_unresponsive_owned_service_escalates_to_kill
test_web_jobs.JobLifecycleTests.test_real_timeout_stops_process_and_marks_failure
test_web_jobs.JobLifecycleTests.test_running_cancellation_stops_owned_process_and_nested_child
test_webapp.HTTPApiTests.test_evaluation_snapshot_is_available_at_local_endpoint
test_webapp.HTTPApiTests.test_evaluation_snapshot_reports_measured_scope_and_handles_missing_artifacts
```

启动回归通过模拟 `execv` 检查参数边界，并核对生成配置及各入口使用的解释器选择函数。Windows 下另行尝试 shell 启动时，遇到 C 运行库对含空格解释器路径的参数处理问题。完整 shell 启动与推理部署仍需在目标 Linux 平台复核。
