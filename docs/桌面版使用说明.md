# 应急先行桌面预览版

面向当前 Orange Pi 的 Debian ARM64 桌面环境，使用本机已有的 GTK 3 和 WebKitGTK 4.1。窗口内置工作界面和本地服务，不用另外打开浏览器。

## 安装与启动

在项目目录运行 python3 tools/install_desktop.py，会安装应用菜单入口和桌面“应急先行”快捷方式。若提示未受信任，右键选择“允许启动”。

也可以在板卡图形桌面的终端运行：

    cd /home/orangepi/emergency-agent
    bash start-desktop.sh

检查组件与当前图形连接：

    python3 desktop_app.py --check

受限执行环境或 SSH 会话没有图形连接时不能显示窗口，display_available 会返回 false。

## 工作空间

默认进入持续监测。左侧可切换现场分析、巡查记录、批量测试、知识库，切换时保留监测和表单状态。五段本地照片演示视频可直接选择。

F11 切换全屏，F5 重新加载。应用菜单可打开报告与证据、演示视频、运行日志及关于信息。报告与证据使用独立查看窗口，文件下载使用系统保存对话框。

桌面事件通知默认开启，可在菜单关闭。首次进入不重复通知已有事件，新活动事件及连续检出升级会请求系统通知；实际显示取决于桌面通知服务及勿扰设置。声音仍需在监测页点击启用。

## 服务与数据

通常应用自动启动只监听本机回环地址的服务，退出时关闭，检测也停止。已有检测或分析任务时退出会提示，已保存的记录与证据保留。若连接的是先前已启动的兼容网页服务，底栏会显示关闭窗口后后台继续运行。

继续使用原模型配置及 data 目录。桌面日志在 data/desktop/desktop.log，服务日志在 data/desktop/backend.log。桌面预览版使用内置 WebKit 渲染界面，尚未打包成可在任意电脑运行的独立安装包；模型能力和误检漏检情况沿用现有项目。
