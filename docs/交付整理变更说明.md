# 原版代码的交付整理范围

本文记录初次交付整理。后续 GitHub 仓库整理与本机验证见 [仓库整理与验证说明](仓库整理与验证说明.md)。

基线是 2026-11-24 原版 emergency-agent；原目录未改动，指纹见 benchmarks/original_source_sha256.json。

- 保留完整 Agent、风险规则、HTTP 后端、前端、桌面壳、监测、检测与模型导出/诊断工具的源码。
- 启动脚本去除原机硬编码解释器；config.example.json 与配置生成器替代公开提交机器 config.json。
- 可选转换/诊断/批处理工具的默认路径移到本副本，使用明确环境变量指定外部运行时。
- 演示生成器使用独立导入的样例，不再从原项目历史 evidence 取照片；检测逻辑与阈值保持原版。
- 软件测试使用合成空白图和模拟模型指纹 / 历史报告；真实精度与性能测量单独归档。NPU 激活逻辑测试中的“通过”是 mock，未写入原机配置。
- 新增部署、资源导入校验、真实模型验证、健康检查、CPU 计时、软件测试、PDF 构建与 GitHub CI 配置。
- 新 README 和白皮书给出当前结论；旧 docs 保留并标明历史性质。

没有把独立 emergency-agent-npu 项目的修复或新编译模型合入本仓库。白皮书中有关拆分输出量化的内容仅作为迁移经验说明。
