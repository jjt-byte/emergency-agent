# 资源准备指南

完整推理需要本地语言模型、两个 DAMO-YOLO 检测模型，以及 llama.cpp 和 Python 依赖。部署脚本还使用验证样例检查模型输出。

## 准确复现原机资源

已有本地交付包的用户可直接运行以下命令。路径替换为实际位置。

```bash
python3 scripts/assets.py models --archive /absolute/path/emergency-agent-models-20261124.tar.gz
python3 scripts/assets.py samples --archive /absolute/path/emergency-agent-local-samples-20261124.tar.gz
```

模型包清单含 35 个文件，样例包清单含 22 个文件。导入器核对文件大小、SHA256 和归档路径。模型包约 2.16 GB，导入后的文件位于 `models/`，样例位于 `samples/`。

这些交付包由项目持有人单独管理，公共下载地址待发布。仓库中的清单可用于核验已有资源。样例包含人物照片和第三方素材，公开再分发需取得相应授权。

## 自行准备资源

无法取得原资源包时，可以在具备模型下载权限和依赖的目标环境中准备以下资源。原资源包导入器要求准确匹配归档清单，自备版本应采用手动配置流程。

1. 按上表放置 Qwen GGUF 和两个 DAMO-YOLO 模型目录。人员与烟火目录须包含对应权重、模型定义、配置和检测器要求的文件。
2. 检查 `tools/detect_person.py`、`tools/detect_fire_smoke.py` 的 `MODEL_FILES`，为每个模型目录生成 `source.json`。其中 `sha256` 字段是相对文件名到实际 SHA256 的映射。记录所用模型的来源和许可。
3. 建立 `.venv`，安装 `requirements.txt`，运行 `bash scripts/build_llama.sh` 构建 llama.cpp。
4. 执行 `.venv/bin/python scripts/configure.py --runtime-python "$PWD/.venv/bin/python" --llama-cli "$PWD/vendor/llama.cpp/build-cpu/bin/llama-completion"`。
5. 准备有使用授权的人工验证样例，按 `scripts/validate_models.py` 和 `tools/setup_fire_smoke.py` 中的样例路径和预期调整本地验证程序，再运行实际模型验证。
6. 执行 `.venv/bin/python tools/init_knowledge.py` 和 `.venv/bin/python scripts/doctor.py`，核对检测器状态后运行 `bash start-web.sh`。

修改模型、阈值、检测脚本或路径后，需要重新生成实际验证结果。验证文件中的 fingerprint 由工具依据当前资源计算。历史归档用于追溯当时测量。

## 烟火批量评估

批量评估另需两个数据集归档。

```text
data/datasets/smoke_fire_datasets_1/fire_smoke.zip
data/datasets/smoke_fire_datasets_1/fire_600.zip
```

原工具记录的数据集来源为 [smoke_fire_datasets_1](https://modelscope.cn/datasets/davidwu123/smoke_fire_datasets_1)。数据集归档需自行取得并核对使用条款、标注质量和样本来源。

通过网页批量评估入口运行后，结果写入 `data/batches/`。程序汇总固定阈值下的框级 precision、recall、F1，并单独报告 val 部分。训练集与预训练数据的重叠情况尚待核实。

## 可选 NPU 对比

`tools/compare_person_npu.py` 从 `data/person_detection_validation.json` 读取样例。历史六张图的名字和人工人数参考保存在 `benchmarks/historical/person_detection_validation.json`，图像文件由本地样例包提供。完整对比前需核对每张图的本机路径与人数参考，再运行板端测试。历史记录包含远景人员参考不完整的问题，人工复核后才能评估候选模型。

新部署生成的人员验证记录只有三人图与空白图两项。补齐六项参考后，对比程序才会进入完整样例判定流程。运行时就绪状态由本机实际验证生成。
